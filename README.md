# BallShiftDFS

Учебное приложение Windows Forms (C#, .NET Framework 4.8) — лабораторная работа №1 «Двигаем шарики»
(вариант 14): решение головоломки поиском в глубину (DFS) с визуализацией и анимацией найденного пути.

## Правила головоломки

- Поле 4×4, в каждой клетке шарик одного из 4 цветов.
- Ход — циклический сдвиг одной строки (влево/вправо) или одного столбца (вверх/вниз).
  В каждом состоянии доступно 16 ходов.
- Нужно преобразовать начальное расположение шариков в целевое.
- Ходы только переставляют шарики, поэтому количество шариков каждого цвета — инвариант.
  Если оно различается у начального и целевого состояний, цель недостижима (приложение проверяет это до запуска поиска).

## Возможности

- Редактирование начального и целевого состояний кликами по шарикам, случайная генерация.
- Запуск DFS в фоновом потоке (интерфейс не зависает) с итеративным углублением: если заданной глубины (1–200, по умолчанию 25) не хватает, она автоматически увеличивается, а найденное значение подставляется в поле глубины.
- Статистика поиска: число итераций, максимальный размер списка O, размер O на момент завершения,
  максимум |O| + |C|, затраченное время.
- Пошаговая анимация найденного пути с описанием каждого хода.

## Структура проекта

| Файл | Назначение |
|------|------------|
| `BallShiftDFS/Program.cs` | Точка входа. |
| `BallShiftDFS/State.cs` | Состояние задачи: поле упаковано в одно `uint` (2 бита на клетку), генерация дочерних состояний (`GenerateChildren`), сравнение и хэш по одному числу, ссылка на родителя для восстановления пути. |
| `BallShiftDFS/DfsSolver.cs` | Поиск в глубину с итеративным углублением: отсечение по нижней оценке числа ходов, ограниченная хэш-таблица посещённых состояний, ходы — битовые операции над `uint`. Находит кратчайший путь, глубина растёт автоматически. |
| `BallShiftDFS/BallGridControl.cs` | Собственный контрол для отрисовки и редактирования поля 4×4. |
| `BallShiftDFS/Form1.cs` | Главная форма: интерфейс, запуск поиска, статистика, анимация, загрузка/сохранение. |

## Сборка и запуск

Требуется Windows с .NET Framework 4.8 и Visual Studio (или MSBuild):

1. Открыть `BallShiftDFS.sln`.
2. Собрать и запустить проект `BallShiftDFS`.

## Замечания по анализу кода

- Итеративное углубление гарантирует кратчайший путь и полноту поиска (для достижимой цели), поэтому прерываний по памяти нет.
- Время поиска растёт с расстоянием между состояниями; на типичных случайных парах (8–10 ходов) оно составляет секунды или меньше.
- Состояние упаковано в `uint` (2 бита на клетку), что снижает расход памяти и ускоряет сравнение.
